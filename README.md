# 湖北视感闪租 · 相机库存管理

这是一个只保留“库存看板”和“相机库存”的本地网站。使用 Node.js 内置模块提供文件持久化，不需要数据库或第三方依赖。

## 启动方式

1. 双击 `start-website.bat`。
2. 浏览器自动打开本地网站。
3. 使用期间保留启动窗口；关闭窗口或按 `Ctrl+C` 可停止服务。
4. 如果 3210 端口被占用，系统会自动使用 3211、3212 等后续端口。

## 固定六大类

- 手持云台
- 全景运动相机
- 微单相机
- 卡片相机
- CCD相机
- 落地三脚架

每个大类都可以手动新增、改名和删除小类目。每个小类目下可以新增机型。

## 机型字段

- 型号
- 串码 SN，仅允许字母或数字，最长 32 位，建议约 15 位
- 成色
- 是否在保
- 激活时间
- 在保到期时间
- 随心换 / 无忧换到期时间
- 是否已出售
- 备注

表格中的字段修改后会自动写入数据文件。

## 复制同型号

- 勾选且只勾选一个机型后，“复制同型号”按钮会启用。
- 可在同一大类下选择任意小类目作为目标。
- 可自行填写复制数量，一次支持复制 1-100 条。
- 每条新记录只复制型号，SN、成色、在保、激活时间、随心换、售出状态和备注全部为空。
- 复制完成后自动聚焦新行的 SN 输入框，直接填写即可。

## 移动 SN

- 每条 SN 右侧都有移动按钮，可单独移动到其他大类和小类目。
- 勾选多条 SN 后，可使用“移动所选”批量移动。
- 目标小类目可以选择已有小类目，也可以在移动时直接新建。
- 移动后立即写入 `data/state.json`。

## Excel / Word 一键导入

点击页面上的“导入 Excel / Word”，选择文件后系统会自动识别、分类并写入库存，不需要手工逐条填写。

支持格式：

- `.xlsx` / `.xlsm`：Excel 工作簿、宏启用工作簿
- `.xltx` / `.xltm`：Excel 模板
- `.docx` / `.docm`：Word 文档、宏启用文档
- `.dotx` / `.dotm`：Word 模板
- `.csv` / `.tsv`：表格文本文件
- 旧版 `.xls` 和 `.doc` 请先另存为 `.xlsx`、`.xlsm`、`.docx` 或 `.docm`
- Excel 二进制 `.xlsb` 暂不支持，请另存为 `.xlsx` 或 `.xlsm`

自动识别内容：

- 大类、小类目、型号、SN、成色
- 是否在保、激活时间、在保到期时间
- 随心换 / 无忧换到期时间
- 是否已出售、备注

如果 Excel/Word 中没有写大类或小类目，系统会根据型号和品牌自动判断。例如：

- 大疆 Pocket / Osmo → 手持云台 / 大疆
- 影石 Insta360 / Ace Pro → 全景运动相机 / 影石
- 佳能 R50 → 微单相机 / 佳能
- 佳能 G7 X3 → 卡片相机 / 佳能
- 佳能 IXUS → CCD相机 / 佳能
- 富宝图 / 三脚架 → 落地三脚架 / 富宝图

导入完成后，页面会显示新增、更新、跳过和警告数量。识别到的数据会直接保存。

## 文档同步规则

- 有 SN 的机型按 SN 与网站现有记录匹配。
- 文档中识别到的字段与网站不同时，以文档内容为准覆盖。
- 文档中没有提供的字段保留网站现有数据。
- 文档中没有 SN 的机型会作为“待补录 SN”同步，不会跳过或丢失。
- Excel 中每个工作表会作为对应小类目名称。
- 重复导入同一文档不会新增重复记录，只会更新已有记录。

## 数据保存位置

- 主数据文件：`data/state.json`
- 自动备份：`data/backups/`
- 导入归档：`data/imports/`

直接双击 `index.html` 时无法写入网站文件夹，正式使用必须通过 `start-website.bat` 启动。
